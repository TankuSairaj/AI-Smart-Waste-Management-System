About the project

Colleges produce waste in classrooms, canteens, hostels and sports grounds. Without a clear picture of where it collects, cleanup is slow and recycling is inconsistent. This system brings detection, reporting and guidance into one place.

🔎

Identify

Upload a photo of a campus area and let an AI vision model list the waste it can see, with a category for each item.

📍

Locate

Every detection and report is tied to a named place, such as Canteen Block or Hostel Gate, so hotspots stand out.

Recycle

Plain-language instructions for plastic, paper, glass, metal and organic waste help people sort at the source.

AI waste detection

Upload a photo and enter where it was taken. The image is analysed on the server by a vision model. If the server has no API key configured, no AI analysis is run and you can tag the waste manually instead.
